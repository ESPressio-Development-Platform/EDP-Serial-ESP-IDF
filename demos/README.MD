# EDP-Serial-ESP-IDF demonstration index (0.1.0)

[UartFifoByteStreamWriter](UartFifoByteStreamWriter/README.MD) has **Arduino IDE, PlatformIO Arduino, and PlatformIO ESP-IDF** concrete source layouts. The safe default validates the IDF-backed ESP32 Composition provider without selecting hardware pins or transmitting. Explicit opt-in native UART setup/transmission requires two application-specified pin macros and exclusive control of UART1, and does **not** prove wire receipt without external capture. The Arduino targets use the ESP32 Arduino core's underlying IDF UART API; this package does **not** implement the separately deferred generic EDP-Serial-Arduino library.

Private GitHub dependencies require a Git account with repository access. Configure authentication in Git outside the demo manifest; the URLs contain no credentials.
