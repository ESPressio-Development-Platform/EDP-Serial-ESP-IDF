# Build tooling reference

No maintained independent Python/code generator or UART monitor is part of this repo. The public native source is only the two C++20 headers. **`tests/run_host_tests.sh`** compiles and runs `tests/UartFifoByteStreamWriterTests.cpp` with scripted fake `driver/uart.h`, real EDP-Serial + EDP-System source roots and selected `CXX`; it does not install a native UART, send wire bytes or attach physical RX. The **`CMakeLists.txt`** exports the real IDF UART driver requirement `esp_driver_uart` plus abstract `edp_serial` source and no invented concrete provider; the consuming app must supply its CMake component naming. The **PlatformIO manifests** select C++20 framework, board and sibling library source, with app-specific override of real pin selection only when explicitly configured. Any target compile/link or physical capture result belongs in [Build/Test/Source](Build-Test-and-Source), with exact run ID and source SHA.
