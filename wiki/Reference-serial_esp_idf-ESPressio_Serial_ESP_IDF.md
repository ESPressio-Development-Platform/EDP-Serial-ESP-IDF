# src/ESPressio_Serial_ESP_IDF.hpp — PUBLIC native provider umbrella

The only purpose of this maintained header is to provide the ordinary consumer a stable include `<ESPressio_Serial_ESP_IDF.hpp>` which aggregates the sole concrete native `<serial_esp_idf/UartFifoByteStreamWriter.hpp>` declaration. **No additional Type, method, enum, constant, alias, compiler definition, instance or initialization logic is declared in the umbrella**. Importing it introduces the real SDK dependency on `driver/uart.h` and EDP-Serial's abstract EDP-System provider contracts; it does not select a UART port, install a driver or create a worker. The actual public and private member semantics, exact native call, bytes-accepted/WouldBlock status, lifecycle and real target exclusions are in [UartFifoByteStreamWriter](Reference-serial_esp_idf-UartFifoByteStreamWriter). The umbrella itself has no independent resource footprint beyond compilation dependencies.
